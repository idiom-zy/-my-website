# 周颖 · 个人设计作品集

个人 UI/UX 与平面设计作品集网站，使用 HTML、CSS 和原生 JavaScript，无需安装依赖或构建。浏览器打开 index.html 即可查看，也可部署到静态网站托管服务。

- index.html：首页、个人介绍与作品目录
- project.html：项目详情
- main.js：项目内容
- motion.js：首页线条与滚动交互
- style.css、experience.css：样式与响应式布局
- assets/：作品图片与个人照片

包含 Naro 娜渃、师融百工、灵悉、一木一界、菠啤狂欢、向阳花开六个项目。

作品图片及个人照片属于作者，未经许可请勿转载。
